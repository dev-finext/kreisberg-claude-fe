# Code conventions (read before adding screens)

## Stack
Vue 3.5 `<script setup>` SFCs (no TypeScript), Pinia (options API stores), vue-router 4, Vite. RTL-first: `<html dir="rtl">`; in flex rows the FIRST DOM child is the RIGHTMOST on screen. ESLint (flat) + Prettier — run `npm run lint` before finishing.

## Design tokens
All colors/radii/shadows/fonts come from CSS custom properties in `src/styles/tokens.css`. NEVER hardcode a hex that exists as a token. Base primitives in `src/styles/base.css`: `.btn .btn-primary .btn-secondary .btn-text .btn-danger-text`, `.input .select .field-label`, `.pill .pill-info .pill-success .pill-neutral`, `.scroll-slim`, `.num` (LTR-isolated tabular numbers — use on every number/date/code), `.item-code`, `.ellipsis`.

## Shared components (`src/components/shared/`)
- `AppIcon.vue` — `<AppIcon name="pencil" :size="18"/>`; names: chevron-down/left/right, eye, eye-closed, plus, plus-circle, kebab, drag, search, pencil, trash, copy, paste, cancel, note, clock, info, megaphone, check, check-circle, alert-circle, menu-projects, menu-reports, menu-system, menu-settings, collapse.
- `BaseModal.vue` — props: title, width, confirmLabel, cancelLabel, confirmDisabled, hideFooter; emits close/confirm; slots: default, subtitle, footer-extra. Style: title Bold16 `--text-secondary` right, ✕ left, divider, footer buttons.
- `BaseToggle.vue` (35×20), `BaseCheckbox.vue` (size "small"|"regular"), `SearchPill.vue` (modelValue, placeholder, width), `ContextMenu.vue` (items [{key,label,icon,danger,disabled}], x, y; emits select/close), `DeleteConfirmModal.vue` (title, message, detail, confirmLabel).

## Data & stores
Single reactive DB: `useDbStore()` (`src/stores/db.js`) — `db.db.<collection>` for writes, getters for reads, `db.persist()` after each mutation, `db.nextId("collection")` for ids. Domain logic: `useBoqStore`, `useCatalogStore`; toasts/prefs/clipboard: `useUiStore().toast(text, type)`.
Demo data lives in `demo-data/db.json` (generated by `demo-data/generate.mjs`, alias import `@demo/db.json`). It is throwaway — never import demo data anywhere except `src/stores/db.js`.

## Constants & utils
`src/constants.js` (PRIORITY, PRIORITY_LABELS, BOQ_STATUS_LABELS, SIDEBAR_MODE, …), `src/utils/format.js` (formatDate, formatTime, formatDateTime, formatQty). Use them — no local duplicates.

## Screen anatomy (match existing screens)
Page = `PageHeader` (breadcrumb + title + actions slot) above a white `.card` (radius `--radius-card`, min-height calc(100vh - 130px)). Project tabs render inside `ProjectView.vue`'s card. System screens (קטלוגים, ניהול תגיות, מיפוי) are top-level routes with their own PageHeader + card. Tables: header 13px/500 `--text-secondary`, 1px `--divider` rules, rows 44-48px, hover `--surface-subtle`, checked `--brand-primary-soft`. Group headers on `--surface-subtle`. Side panels: 291px, border-left 2px `--divider`, rows 32px radius 8, selected `--brand-primary-soft`.

## Rules
- Every visible button must perform its real action against the db store (this is a fully-working demo).
- Hebrew strings must match the Figma frames exactly; numbers/dates get `.num`.
- No new npm dependencies.
- Keep components under ~350 lines; split otherwise.
